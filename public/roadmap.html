PolicyLens · path to enterprise-grade

A grounded IAM auditor is the right thesis. Getting there is a data & trust problem, not an AI one.

The defensible core already holds: a deterministic engine produces every permission fact, the LLM only explains it, and each answer cites source lines. Conversational, cited interrogation of policies is a real market gap — findings scanners don't do it.

The honest gap: ~70% of "enterprise-grade" is completing permission data, evaluation semantics, live ingestion, and trust infrastructure. The trap is going shallow on four clouds at once. So we scope AWS-first — depth on one beats breadth on four for security buyers.

Where HuggingFace actually fits

Self-hostable explanation model

The real enterprise selling point: air-gapped buyers won't send IAM policies to an external API. Ship the explanation layer on an open model via vLLM with grammar-constrained decoding — it only narrates verdicts the engine already produced.

Qwen3-14B/32B (Apache-2.0) default · Llama-3.3-70B premium · Phi-4 fallback

Embeddings as a suggestion layer

Embed the ~18k AWS action descriptions; retrieve nearest actions for a free-text question. The deterministic engine still decides — embeddings never assert a permission.

Qwen3-Embedding-0.6B or bge-m3

What HuggingFace is not: there's no pretrained model that reliably judges "is this over-permissive," and no canonical IAM policy dataset. Model fuzziness stays out of the decision path by design. The permission data comes from GitHub (iam-dataset), and our eval corpus gets built by labelling generated policies with Access Analyzer verdicts.

Top risks

1False negatives at enterprise stakes. A wrong "no" is a security incident. Mitigation: Access Analyzer as ground truth (G1 exit gate); never claim "safe" — only "no findings in the checks run."
2Ingestion breadth. Real orgs have thousands of policies plus SCPs and boundaries. Mitigation: scope to identity/resource/trust first; label SCP/boundary interplay "not yet evaluated" explicitly rather than silently ignoring it.
3License contamination. PMapper and ScoutSuite are copyleft. Mitigation: reference-only, clean-room edge semantics; everything vendored is MIT / BSD / Apache.
