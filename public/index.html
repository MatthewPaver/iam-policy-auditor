Keep a record of the review

    
Export the original review, correction and source evidence in one JSON record.

    
What the record includes
The permission request
Current and proposed policies, the action, resource and supplied condition context.
The reason for review
A deterministic result and the statement and source line behind it. The original proposal stays visible.
The correction check
Risk closure, required-access preservation and introduced high or critical findings, checked separately.
The portable record
Exact inputs, SHA-256 identities, engine and schema versions, citations, corrected outcome and scope limits.

    
Limits
A checked correction covers only the supplied policies and the access requests you declare. It is not an account-wide safety check or production approval.
Which account rules are outside this check?
Organisation-wide restrictions, limits on roles, temporary-session rules and cross-account access are excluded. Engineers know these as SCPs, permission boundaries, session policies and cross-account interactions.
AWS Access Analyzer already provides new-access checks. PolicyLens offers a smaller, inspectable workflow. Independent comparison with the AWS simulator remains outstanding.
