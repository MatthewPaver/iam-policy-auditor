# Self-hosted product type

Hanken Grotesk is distributed under the included SIL Open Font License (OFL.txt). The variable Latin woff2 comes from the `@fontsource-variable/hanken-grotesk` 5.3.0 npm package, the same file the portfolio site at matthewpaver.github.io serves, so PolicyLens and the portfolio share one type family. It is stored locally so the product makes no runtime font-service request.

The existing PolicyLens magnifying-glass brand mark is retained. New interface symbols use consistent small outline SVG geometry. They are functional controls and labels, not illustrations.
